# גיבורי הדרך – Safe Street Heroes 🚸

משחק תלת־ממד בדפדפן ללימוד ילדים בטיחות בדרכים: חוצים במעבר חצייה, מחכים לאיש הירוק, ומסתכלים שמאלה, ימינה ושוב שמאלה.
העיר במשחק בנויה משטיח משחק לילדים: השטיח הוא הרצפה, והבניינים מתרוממים ממנו כמו בספר קופץ.

A 3D browser game that teaches children road safety, built from a kids' city play-carpet.

## איך משחקים · How to play

פותחים את `index.html` בדפדפן, או את הקישור של GitHub Pages. לא צריך להתקין כלום.

- **מקלדת:** חיצים / WASD להליכה · רווח = להסתכל · M = מפה
- **טאבלט / טלפון:** כפתורי החצים וכפתור 👀 "הסתכלו"
- כפתור **EN / עב** מחליף שפה (עברית / English), עם הקראה קולית.

בכל השלבים הילד הולך יד ביד עם מבוגר, חוץ משלב הכדור ומשלב "יד ביד", שבהם הילד צריך ללכת בעצמו אל המבוגר.

ב־GitHub: **Settings → Pages → Branch: `main` / root → Save**.
אחרי כדקה המשחק יהיה זמין בכתובת `https://<user>.github.io/<repo>/`.

## איך זה בנוי · How it's built

- **Three.js** (WebGL) בדפדפן, בלי Blender ובלי מנוע משחק.
- `source/make_assets.py` חותך כל בניין מתמונת השטיח (`assets/carpet.png`), מסיר את הדשא והשמיים מסביב, וממלא את מקומו ברצפה בצבע דשא.
- `source/game_src.html` מכיל את המשחק: מכוניות, רמזורים, דמויות וחוקי הבטיחות.
- `source/build.py` מאחד הכול לקובץ אחד: `index.html`.

```bash
pip install pillow numpy
python3 source/make_assets.py assets/carpet.png
python3 source/build.py
```

כדי לבנות עיר משטיח אחר, מחליפים את `assets/carpet.png` ומעדכנים ב־`game_src.html` את מיקומי הכבישים ומעברי החצייה (בפיקסלים של התמונה), וב־`make_assets.py` את מסגרות הבניינים.
